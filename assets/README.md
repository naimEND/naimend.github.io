# Your own media files

Put your portfolio images and optional video previews in this folder.

Example:

- `hero.jpg` — full-screen homepage photograph (or `hero.mp4` for a muted video background)
- `about.jpg` — portrait / behind-the-scenes image
- `project-one.jpg` — first film's poster frame
- `project-one-preview.mp4` — optional short preview for true timeline scrubbing

Then update the relevant `image`, `video`, or `previewVideo` path in `../content.js`.

The starter's photos are currently *linked* from the B12 demo site's CDN rather than copied here. Please replace them with files you have permission to use before making the portfolio public.
